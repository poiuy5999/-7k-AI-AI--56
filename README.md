# 源码7k-AI创作小程序源码，文生图，图生图，可对接任何图像AI模型

源码获取：ym7k.com/19846/源码7k-AI创作小程序源码，文生图，图生图，可对接任何图像AI模型

这套 AI 创作小程序源码基于微信小程序生态开发，主打文生图、图生图两大图像生成能力，采用模型解耦网<img width="1431" height="945" alt="完整" src="https://github.com/user-attachments/assets/0c3a10ef-cb21-4ed4-94e5-c6c1cb6b2f14" />
关架构，不绑定单一图像生成模型，支持灵活接入各类开源或商用图像大模型接口，是轻量化 AIGC 图像创作平台的工程方案，适合开发者研究 AIGC 前端交互、任务调度、异步推理的落地思路。

小程序前端围绕创作者的使用流程搭建，页面模块划分清晰，包含提示词输入面板、风格选择、参数配置、参考图上传、作品预览、创作历史、个人中心等组件。文生图模式下，用户可以填写正向提示词与负面提示词，自定义图片分辨率、采样步数、CFG 权重、采样器等参数，提交生成任务；图生图模式支持上传参考图像，设置重绘幅度，在保留原图构图、主体结构的基础上，结合提示词完成风格迁移、画面扩图、局部重绘。系统采用异步任务机制处理图像生成，规避小程序接口超时限制，生成完成后回调结果，支持图片保存、收藏、作品管理，适配移动端碎片化创作场景。

后端核心亮点是独立的模型网关层，实现业务逻辑与模型推理服务解耦，做到模型可插拔。网关定义统一的请求入参、出参规范，不管是本<img width="300" height="200" alt="2026093010393650" src="https://github.com/user-attachments/assets/febe9eed-3940-4ac7-b673-7daa9632aa17" />
地部署的开源扩散模型，还是第三方商用图像 API，只需编写适配适配器即可接入，支持随时切换模型、多模型并行调度。网关统一负责密钥管理、调用限流、请求日志记录、异常捕获与重试，后续根据成本、画质需求调整模型资源时，无需改动小程序前端代码。

系统配套任务队列、权限管控与后台管理面板。图像生成耗时较长，所有创作请求进入队列异步处理，后台可查看任务进度、生成日志。同时内置额度管理模块，支持配置免费次数、次数包、会员权益，精准管控调用消耗。后台支持提示词敏感词拦截、创作记录查看、模型路由配置、接口密钥管理，从源头降低内容风险。代码采用分层模块化设计，前端组件复用性高，后端请求层、队列层、模型适配层相互隔离，新增模型只需要开发对应适配器，拓展成本较低。配套部署文档覆盖小程序上传配置、后端环境搭建、对象存储对接、模型接口调试等内容，方便二次开发，还可按需拓展高清修复、图生视频、提示词广场等功能。

本源码仅用于技术学习与架构研究。如果投入商用运营，需要完善内容审核机制，做好 AI 生成内容合规校验；对接第三方模型时，严格遵守服务商调用协议；同时厘清 AI 生成图像的版权边界，完善用户协议，规避知识产权与内容合规风险。这套方案将小程序轻量化流量入口和可插拔的图像模型能力相结合，摆脱单一模型绑定的局限，兼顾用户创作体验与后端调度灵活性，是搭建轻量化 AIGC 图像创作工具的优质参考方案。
